# 池田哲郎

山梨県甲府市を拠点に、中小企業の補助金申請・融資調達・経営改善を支援している中小企業診断士です。地方銀行で法人融資を担当したあと独立し、2025年4月に池田計画合同会社を設立しました。

- 池田計画合同会社 代表社員（[ikedakeikaku.jp](https://ikedakeikaku.jp)）
- 中小企業診断士・認定経営革新等支援機関・FP1級・ITコーディネーター
- 支援分野：補助金申請支援、融資調達支援、経営の見える化と伴走支援

## 補助金支援の実績（2026年10月時点・自社集計）

5制度で31社中27社が採択され、総支援額は4.3億円を超えています。

| 補助金 | 支援した社数のうち採択 |
|---|---|
| 事業再構築補助金 | 17社中15社 |
| 省力化投資補助金 | 4社中4社 |
| 事業承継・M&A補助金 | 2社中2社 |
| ものづくり補助金 | 5社中4社 |
| 新事業進出補助金 | 3社中2社 |

事業再構築補助金とものづくり補助金は、不採択のあと再申請で採択された社を含みます。詳しくは[採択実績](https://ikedakeikaku.jp/results)をご覧ください。

## 公開リポジトリ

- [subsidy-brain](https://github.com/tetsuroikeda/subsidy-brain)：補助金の名前から、公募要領に沿った申請書の下書きを作り、公式様式に記入するプロトタイプ（2026年5月・架空の事業者データ）
- [grant-finder](https://github.com/tetsuroikeda/grant-finder)：事業者の情報に合う補助金を整理し、締切と公募の見込みを知らせるアプリ（2026年6月）
